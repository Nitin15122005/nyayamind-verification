## Interpretation notes, stated explicitly per this step's rules

- **"13/147" is a count of claims reaching a verifier verdict of ENTAILED, not an
  accuracy figure.** ENTAILED means the small NLI model judged the evidence text to
  support the claim — it is not a validated legal fact. See `src/verifier.py`'s own
  disclaimer, unchanged throughout this project.
- **The natural ENTAILED and CONTRADICTED rows have no baseline/current statistical
  test** because no independent label exists for real natural claims — these are
  reported as before/after counts on the same 147 claims, nothing more.
- **"Cumulative correction shipping" has no true "original" value** — it is a
  single-arm, whole-project-history count, not a paired comparison. It is included
  here for context, not as an ablation result (see `EVIDENCE_STRENGTH_MATRIX.md`,
  which correctly does not grade it above C).
- **Every historical value here was independently reconciled against its source
  artifact** by `build_step8_consolidation.py` before this table was written — none was
  copied without verification. No discrepancy was found (see
  `CONSOLIDATED_CONSISTENCY_REPORT.md`).
