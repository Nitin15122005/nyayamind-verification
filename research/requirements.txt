# Not requested explicitly but required by transformers for device_map="auto"
# used in the original inference.py / instruction_fine-tune.py.
# Pinned to 0.29.3 (contemporary with transformers==4.40.2) instead of latest:
# accelerate's dispatch_model() gates the 4-bit/8-bit force-hooks path on
# model.is_loaded_in_4bit, which transformers 4.40.2 only sets *after*
# dispatch_model() runs inside from_pretrained(). With newer accelerate this
# causes dispatch_model() to fall through to model.to(device) on a device_map
# that resolves to a single GPU, which transformers' own PreTrainedModel.to()
# then rejects for bitsandbytes-quantized models
# (ValueError: `.to` is not supported for `4-bit` or `8-bit` bitsandbytes models).
# accelerate 0.29.3 instead gates on model.is_quantized, which transformers
# 4.40.2 sets earlier (before dispatch_model()), so the force-hooks path is
# taken correctly and .to() is never called.
accelerate==0.29.3
